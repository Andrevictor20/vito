# Chat — o que dá para pedir

## Criar
- "Marca dentista amanhã às 14h" (evento)
- "Cria a tarefa enviar relatório até sexta" (tarefa com prazo)
- "Guarda trocar o filtro do ar" (pendência)
- "Monitora a PETR3 acima de 35" (radar)
- "Cria um booking de 30 min sábado" (link de agendamento)
- "Me lembra de pagar o boleto amanhã às 8h, todo dia" (tarefa/pendência + lembrete)

## Consultar e organizar
- "O que tenho hoje?" / "minha semana"
- "Remarca o dentista para sexta às 10h" / "cancela o dentista"
- "Marca a tarefa X como concluída" / "agenda a pendência Y para amanhã"

## Sobre o próprio app
- "Como agendo uma pendência?" → passo a passo com caminho na tela.
- "O que você pode fazer?" → resumo das 5 abas com exemplos.
- "Explica tudo do app" → tutorial completo.

## Recursos da conversa
Áudio (transcrição automática), fotos (convites e recibos lidos na hora),
interromper resposta (botão stop), editar mensagem enviada, histórico de
conversas, sugestões rápidas no início.
